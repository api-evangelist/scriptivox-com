Scriptivox provides an AI-powered transcription engine that converts audio and video into accurate text. The service supports 119 languages, offers fast and secure processing, and includes developer APIs, browser-based media tools, and integrations for AI agents. It aims to make transcription accessible for both people and products, with a focus on reliability and scalability.

**Areas:** AI · Transcription · Audio · Video · Developer API

### APIs (7)

- [Scriptivox Account API](https://apis.io/apis/scriptivox-com/scriptivox-com-account-api/) — Balance and pricing information for the calling API key.
- [Scriptivox Discovery API](https://apis.io/apis/scriptivox-com/scriptivox-com-discovery-api/) — Unauthenticated description of the API itself — endpoints, auth scheme, rate limits and versioning policy.
- [Scriptivox Feedback API](https://apis.io/apis/scriptivox-com/scriptivox-com-feedback-api/) — Rate a finished job, or report a problem with one. Problem reports are resolved within 24 hours.
- [Scriptivox Status API](https://apis.io/apis/scriptivox-com/scriptivox-com-status-api/) — Whether the API is taking new jobs right now, why not, and what still works. No API key needed.
- [Scriptivox Transcriptions API](https://apis.io/apis/scriptivox-com/scriptivox-com-transcriptions-api/) — Submit, poll, list, cancel and delete transcription jobs.
- [Scriptivox Uploads API](https://apis.io/apis/scriptivox-com/scriptivox-com-uploads-api/) — Presigned upload URLs for files that are not reachable at a public URL.
- [Scriptivox Webhooks API](https://apis.io/apis/scriptivox-com/scriptivox-com-webhooks-api/) — Signed event callbacks to your webhook_url, retried with backoff, plus a test event and a resend for any finished job.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Scriptivox: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
